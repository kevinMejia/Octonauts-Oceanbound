# Original music source

`background_music.weba` is the original supplied full-length stereo Opus/WebM recording. It is retained for future re-encoding. The game plays `../oceanbound-background.mp3`, its Safari-compatible conversion. This source folder is excluded from production builds.

The old `assets/sounds` folder also contained byte-identical copies of the propeller, ambience and bubble MP3s already in `assets/audio`. Those verified duplicates were removed; all runtime audio lives in `assets/audio`.
